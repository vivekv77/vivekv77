## Vivek Iyer

Founder at [FortunaTerra](https://github.com/FortunaTerra-Group). I build products with coding agents and publish the discipline that keeps them honest.

**Governed agentic delivery for teams already shipping with coding agents: contract before code, verification before merge.**

### Public standards and skills

| | What it is |
|---|---|
| [CHOP](https://github.com/FortunaTerra-Group/chop) | Ten rules for state that coding agents modify, plus the V1 to V5 verification addendum. A standard, not a library. |
| [goal-contract](https://github.com/FortunaTerra-Group/goal-contract) | What done means, how you will know, and who checks, written before an agent writes code. Pattern, schema, worked example, Claude Code skill. |
| [multi-persona-review-panel](https://github.com/FortunaTerra-Group/multi-persona-review-panel-skill) | Independent reviewer lenses on your diff before the PR, one verdict per lens. |
| [usability-heuristic-review](https://github.com/FortunaTerra-Group/usability-heuristic-review-skill) | Heuristic evaluation of the surface that shipped, a severity on every finding. |
| [layered-tdd-mandate](https://github.com/FortunaTerra-Group/layered-tdd-mandate) | Five test layers, L0 to L5, and which one actually catches a given class of bug. |
| [loop-quality-standard](https://github.com/FortunaTerra-Group/loop-quality-standard) | Accuracy, reasonableness, and liveness checks for an agent's recurring output, not just its code. |

Install the skills: `claude plugin marketplace add FortunaTerra-Group/claude-plugins`
